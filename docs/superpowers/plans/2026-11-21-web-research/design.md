# 网页调研设计

## 调研

- 可复用 Pi 模型适配、桌面 IPC 和主进程凭据保险库、Runtime 对话持久化、脱敏日志与断线反馈。本地资料有独立来源台账，可参考其对话内交互。
- 缺少公众网页搜索适配、搜索服务设置、调研请求的明确发送边界、可信来源映射及结果的证据等级。

## 改动与接入

1. 使用 Brave Web Search API HTTPS POST。用户在「网页调研」模式发送的文字是搜索服务收到的查询。限制 400 字符、50 词、8 条候选、512 KiB 响应和 12 秒。禁止重定向。搜索密钥存于独立的 Electron safeStorage 目录。
2. 用同一 Pi 底座整理搜索摘要。调研轮次收到当前查询和有界摘要，无历史、附件、Skills、MCP、插件或工作区工具。已有普通对话 transcript 保持独立。
3. Harness 要求模型输出结构化结论与引用编号。仅接受当前查询中确实提供的编号。缺失、无效和明确待核实的条目标成「无法核实」。模型提供有效编号时标成「依据搜索摘要 · 原文未核对」。零结果时不调用模型。解析失败显示证据不足并保留来源索引。已返回的资料编号代表可追溯性，不能证明来源支持该结论。
4. 调研消息随对话保存结构化结论和带域名的来源索引。搜索设置有密码字段及保存、移除反馈。发送框标出外发范围，结果用结论、证据标签、可复制 URL 的折叠来源表。远程标题和正文按文本渲染。

官方接口参考为 https://api-dashboard.search.brave.com/api-reference/web/search/post 。本切片将摘要与未获证据明确区分，后续可独立扩展原文读取和多轮证据比对。

## 风险与失败路径

- 搜索结果或网页摘要可含不可信指令。只作为 Pi 用户消息中的数据传入，调研轮次没有外部操作工具。密钥只用于分别访问对应服务，日志只保留状态和耗时。
- 搜索服务拒绝、限流、超时、响应损坏均返回可区分错误，失败时保留输入；不从模型常识补上搜索失败。
- 结论与引用映射只验证编号，界面标出证据等级。域名和 HTTPS 地址来自服务响应，内容和链接不在 Electron 内加载。
