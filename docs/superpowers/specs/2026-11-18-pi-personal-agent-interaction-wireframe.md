## 主导航

```text
┌ Pi Personal Agent ────────────────────────────────────────────── Runtime 状态 ┐
│ 工作台       任务       历史记录                              诊断   设置      │
└───────────────────────────────────────────────────────────────────────────────┘
```

- 工作台、新对话：始终可见。打开当前对话和发送区。
- 任务：始终可见。只列出真实持久化任务，含待审批、运行中、暂停、需处理和终态。
- 历史记录：仅当会话历史列表能力接入后显示；当前阶段不展示空壳入口。
- 诊断、设置：作为稳定次级入口；设置进入模型设置，诊断显示日志位置与关联错误。
- 运行中任务的选择不改变任务状态。恢复冻结时全局状态条固定显示冻结原因，相关副作用按钮禁用。

## 工作台主页

```text
┌ 当前对话 ────────────────────────────────┬ 当前上下文 ───────────────┐
│ 模型：Provider / Model · 连接状态         │ 当前任务（无任务时收起）  │
│                                           │ 目标 / 状态 / 权限 / 预算 │
│ 消息时间线                                │ 进度 / 产物 / 投递状态    │
│                                           │                           │
│                                           │                           │
├───────────────────────────────────────────┴───────────────────────────┤
│ [普通对话 | 本地任务提案]  输入内容…                     [发送 / 提案] │
└───────────────────────────────────────────────────────────────────────┘
```

- 模型未连接或配置已变更：普通对话模式可见但发送禁用，旁边提供“打开模型设置”；不会显示可用状态。
- 连接测试成功：显示当前 Provider/Model 与测试时间；每次真实聊天请求仍单独显示请求中、成功、错误或超时。
- 费用未知与 tokens 分开表达，不把 token 用量推断为费用。
- 本地任务提案模式当前明确标记为确定性本地流程；只有接入模型提案和审批合同后，才改称 Agent 任务提案。
- 小窗口时，任务上下文改为可开合的侧栏/抽屉；对话输入区始终可达，窄屏不强制双栏最小宽度。

## 对话与任务提案

```text
用户消息：整理本周资料，列出来源并生成报告
模型回复：普通自然语言答复，显示模型与用量/费用状态

任务提案：当前目标、输入范围、输出文件、权限、预算、验收方式
            [编辑提案] [批准并执行] [拒绝]
```

- “发送消息”：只在模型已配置、用户主动连接测试成功、输入非空且无请求进行时启用。成功后只显示实际 provider 响应；失败保留输入并显示错误摘要和关联 ID。
- “创建本地任务提案”：当前只建立确定性报告任务，不声称模型规划；成功后显示待审批合同，失败不清空输入。
- “编辑提案”：仅在尚未批准时显示；保存会更新提案版本。实质修改审批范围后必须重新审批。
- “批准并执行”：仅待审批任务可见。成功后进入排队/执行状态；失败保留审批页并说明权限、预算或 Runtime 错误。
- “拒绝”：仅待审批可见；需要确认后进入已取消/已拒绝状态，失败保留原状态。

## 任务详情

```text
任务目标                                      [更多操作]
状态 / 当前步骤 / 最近更新时间
批准版本：合同摘要、权限范围、预算上限
步骤：等待 → 执行 → 验收
产物：路径、大小、校验结果                     [打开产物]
通知：未请求 / 待发送 / 已送达 / 失败 / 结果未知
错误：原因、影响、下一步、关联 ID              [重试] [查看日志]
```

- “暂停”：仅运行中显示。发出暂停请求后显示处理中；收到持久化暂停确认后才显示已暂停。失败保持运行/未知状态并显示关联 ID。
- “恢复”：仅暂停且恢复门禁通过时显示；冻结、未知副作用或缺失插件定义时禁用并解释原因。成功显示排队，失败保留当前状态。
- “取消”：运行/排队时显示次级操作并二次确认。成功只表示本地任务进入取消状态；已有外部副作用不被描述为回滚。
- “重试”：仅失败且原因可重试时显示；开始前显示将重试的步骤和预算影响。未知费用/发送状态下禁用，等待用户处理。
- “打开产物”：仅验收确认产物存在时显示；文件打开失败时保留路径并显示错误 ID。
- “发送/重发”：当前阶段不提供外部渠道发送按钮。若交付结果未知，必须先展示对账证据和逐条人工处理，不得提供无条件重发。

## 模型设置

```text
Provider       [OpenAI Responses API                v]
模型           [模型标识                               ]
Base URL       [https://.../v1                       ]
API Key        [••••••••••••••••                     ] 已加密保存

连接状态：未测试 / 测试中 / 已连接 / 失败（关联 ID）
[保存配置] [测试连接]
提示：测试向 Base URL 发起真实请求，可能产生费用；该服务可处理 Key 和提示词，本版本无法准确估价。
```

- “保存配置”：配置字段有效且无保存进行时启用。Key 仅由 Electron 主进程使用操作系统加密 API 保存；成功后清空输入框并显示“已安全保存、尚未验证”。失败保留输入并显示错误 ID。留空 Key 表示保留已保存密钥。
- “测试连接”：仅已保存配置与本机加密密钥齐备、配置无未保存更改且无请求进行时启用。按钮由用户主动点击，不做后台探测。实际回复成功才显示已连接；HTTP 鉴权、限流、网络、超时、空回复均显示失败。超时表示费用/用量未知，不自动重试。
- Responses API 请求设置 `store: false`；历史聊天仅包含当前应用标记为模型会话的条目，升级前的聊天内容不会发送。
- 切换 Provider、模型、端点或替换 Key 后清除已验证状态。
- 旧配置文件中的历史明文 Key 在迁移时删除但绝不作为调用凭据；用户必须输入新 Key。

## 日志与错误状态

- 页面顶部状态条只呈现当前 Runtime/恢复冻结/最近一次用户动作状态，不用轮询覆盖动作反馈。
- 每个可恢复错误显示短原因、下一步和稳定关联 ID；长文本、凭据、完整提示词和文件内容不进入日志。
- 诊断页显示日志完整路径、打开日志动作、最近错误列表和复制关联 ID。复制动作成功后给出轻量确认，失败显示具体原因。
- JSONL 路径当前为 `%APPDATA%/<应用名>/logs/runtime.jsonl` 实际值由 `system.status` 返回；UI 显示真实路径而非拼接猜测。
- 日志记录实际 provider 调用开始/结果、延迟、token usage、费用未知标记和错误代码。当前不会写供应商账单金额，因为尚无结算集成。

## 本阶段按钮状态约定

- 提交中的按钮禁用并显示进行中状态，避免重复请求；超时不自动重复收费请求。
- 后端返回 `ok: true` 且真实操作成功后才显示成功；Renderer IPC 失败或 Runtime 错误统一显示失败。
- 保护状态导致禁用时，在按钮附近说明门禁原因，不隐藏任务状态，也不提供强制退出恢复模式的操作。
- 所有操作反馈都保留失败输入/对象，并显示可用于日志检索的关联 ID。
